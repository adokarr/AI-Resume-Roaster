# AI Resume Roaster 🔥

An AI-powered resume reviewer that gives honest, humorous, and helpful feedback to improve your resume.

## 🚀 About the Project

AI Resume Roaster reviews your resume and points out weaknesses in a fun but constructive way. It uses Google's Gemini AI to generate personalized feedback and practical suggestions to help you improve your resume.

## ✨ Features

- **AI-Powered Resume Review:** Get feedback generated by Gemini AI.
- **Funny Resume Roasts:** Discover resume weaknesses through humorous, honest feedback.
- **Actionable Suggestions:** Receive three concrete suggestions for improvement.
- **Input Validation:** Ensures the resume contains at least 200 characters.
- **Responsive Interface:** Designed to work across different screen sizes.

## 🛠️ Tech Stack

- **Frontend:** Next.js, React
- **Backend:** Next.js API Routes
- **AI Integration:** Google Gemini API
- **Language:** JavaScript
- **Package Manager:** npm

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- A Google Gemini API key

## 📖 How to Use

1. Open the application.
2. Enter or upload your resume, depending on the available interface.
3. Submit your resume for review.
4. Read the AI-generated roast and improvement suggestions.
5. Use the feedback to identify areas for improvement.

## 🔐 Security

The Gemini API key is stored in an environment variable and should never be exposed in client-side code or committed to GitHub.

## 🎯 Project Goal

The goal of this project is to make resume improvement more engaging, accessible, and practical through AI-powered feedback.
